# Italiano Snabb – Personlig språkapp

## Vad du har fått

1. **index.html** – Komplett webbapp som fungerar offline (öppna i webbläsare).
   - Spaced repetition flashcards (enkel SM-2)
   - Daglig struktur
   - Lektioner
   - YouTube-sektion med länkar
   - Statistik och framsteg (sparas lokalt i webbläsaren)

2. **italiano-hogfrekvens.csv** – Klar för import i Anki.
   - Front = italienska
   - Back = svenska
   - Example = exempelmening

## Så använder du det

### Webbappen
Öppna `index.html` i valfri webbläsare (Chrome, Safari, Firefox).  
All data sparas lokalt – ingen server behövs.

### Anki
1. Ladda ner Anki (gratis) från ankiweb.net
2. File → Import
3. Välj CSV-filen
4. Sätt separator till kommatecken
5. Mappa kolumnerna: Front, Back, Extra

### Daglig rutin (30 min)
1. 10–12 min flashcards (appen eller Anki)
2. 10 min YouTube / lyssning (börja med “Italiano con Elisa” eller “Learn Italian with Lucrezia”)
3. 8 min produktion – skriv eller prata meningar med dagens ord

## Nästa steg
- Lägg till fler ord i WORDS-arrayen i index.html när du är redo.
- Byt ut YouTube-embeds mot specifika videor du gillar.
- När du har ~800–1000 högfrekvensord: börja med enklare podcasts eller graded readers.

Lycka till med italienskan! 🇮🇹
